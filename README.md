# Windows SSH Plane

> SSH 反向端口转发管理器 · .NET 10 / WinForms 桌面版

把一个需要命令行手敲、还要在控制台里输密码的 SSH 反向转发命令，做成一个双击即用的小工具：
启动弹窗输入密码 → 自动建立转发 → 界面里随时增删/启停每一条 `-R` 规则，断线自动重连。

原来的命令：

```bash
ssh -N -T -p <端口> \
    -o ExitOnForwardFailure=yes \
    -o ServerAliveInterval=30 \
    -o ServerAliveCountMax=3 \
    -R 127.0.0.1:14000:127.0.0.1:4000 \
    <用户名>@<你的服务器地址>
```

> 本仓库不含任何真实服务器地址、账号或密码。服务器地址请在登录框里自行填写，只保存在本机配置文件中（见第四节）。

本程序做的事情完全等价，只是换成了图形界面，并且支持**一条连接上挂多条转发**（原生 `ssh` 一条命令挂多条 `-R` 也可以，但要改命令行重启；本程序可以在线增删，不断开已有转发）。

---

## 一、直接运行

双击 `Windows-SSH-Plane.exe`（`dist` 文件夹内），或在命令行运行：

```
Windows-SSH-Plane.exe
```

运行后会弹出登录框，依次确认/填写：

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| 服务器 | （空，必填） | 对应 `用户名@地址` 里的主机地址，首次运行需自行填写 |
| 端口 | 9787 | 对应 `-p 9787`，按自己服务器的实际端口填 |
| 用户名 | root | 对应 `用户名@` |
| 密码 | （空） | 每次运行手工输入，不落盘 |

点「连接」后：

- 自动建立 SSH 连接，并按表格中**勾选启用**的规则逐条建立反向转发；
- 任意一条转发建立失败，就整体断开并提示（等价 `-o ExitOnForwardFailure=yes`）；
- 连接空闲时每 30 秒探活（等价 `-o ServerAliveInterval=30`），断线后最多自动重连 3 次（等价 `-o ServerAliveCountMax=3`）；
- 关闭窗口会断开连接并退出；点最小化会收进托盘，转发在后台继续跑。

## 二、界面怎么用

- **规则表格**：一行一条 `-R`，四列含义如下（以默认规则为例）

  | 服务器绑定地址 | 服务器端口 | 目标地址（本机） | 目标端口（本机） |
  | --- | --- | --- | --- |
  | 127.0.0.1 | 14000 | 127.0.0.1 | 4000 |

  即 `-R 127.0.0.1:14000:127.0.0.1:4000`，效果是：访问**服务器**上的 `127.0.0.1:14000`，流量被转发到**你本机**的 `127.0.0.1:4000`。

- **添加转发**、**编辑**、**删除**、**启用/停用**：按钮在表格下方，双击表格行也能编辑。
- **勾选/取消「启用」**：连接状态下立即生效，不影响其他规则。
- **直接改表格里的端口/地址**：连接状态下会自动重启该条转发使其生效。
- **修改账号/密码**：右上角按钮，改完会自动重连。
- **空闲超时**：右上角按钮，设置「连续多少分钟没有数据传输就自动断开」，详见第四节。
- **运行日志**：窗口下半部分实时显示，同时写入 `%APPDATA%\Windows-SSH-Plane\app.log`，出问题时先看这里。

## 三、手动选择端口对应

规则里的端口含义（最容易搞反的地方）：

```
-R 服务器绑定地址:服务器端口:目标地址:目标端口
   └── 在服务器上监听 ──┘   └── 转发到你本机这里 ──┘
```

比如想把本机 `8080` 的 Web 服务暴露到服务器的 `18080`，就新增一条：

| 服务器绑定地址 | 服务器端口 | 目标地址（本机） | 目标端口（本机） |
| --- | --- | --- | --- |
| 127.0.0.1 | 18080 | 127.0.0.1 | 8080 |

添加时可以对照弹窗底部实时显示的「等效参数」`-R 127.0.0.1:18080:127.0.0.1:8080` 核对。

> 服务器端口不允许与已有规则重复（弹窗会拦截）；若服务器上该端口已被别的进程占用，界面会在「状态」和「说明」里报错。

## 四、空闲超时自动断开

隧道挂着却没人用的时候，可以设一个空闲阈值让程序自己收尾：**连续多少分钟没有数据传输就自动断开这条 SSH 连接**，默认 **30 分钟**。

- **怎么改**：主界面右上角「空闲超时」按钮，填分钟数保存即可，下一次判定立即按新值生效；填 `0` 表示不自动断开，隧道一直保持到手动断开或网络中断。
- **判定口径**：按 SSH 通道里**实际传输的字节数**计算。保活心跳（每 30 秒一次）不算数据，不会让空闲计时被刷新；每次通道里有数据经过都会重新计时。
- **断开之后**：程序会主动断开连接并写下日志「隧道已连续 X 分 Y 秒没有数据传输，达到空闲超时阈值 N 分钟，自动断开」，状态回到「未连接」，**不会**被断线重连逻辑重新拉起来；需要时点「连接」即可恢复。
- **运行时观察**：主界面顶部实时显示「已空闲 X 分 Y 秒 / 累计流量 / 距自动断开还剩多久」，托盘里也能看到连接是否还在。
- **退回策略**：极少数情况下拿不到通道级数据（SSH 库内部结构变化），程序会退化为「隧道内是否有新连接建立」作为活动信号，并在日志里明确提示，不会静默改变判定口径。

## 五、配置文件与数据位置

| 文件 | 路径 | 内容 |
| --- | --- | --- |
| 配置 | `%APPDATA%\Windows-SSH-Plane\config.json` | 服务器地址/端口/用户名、保活参数、空闲超时（`IdleTimeoutMinutes`）、全部转发规则 |
| 日志 | `%APPDATA%\Windows-SSH-Plane\app.log` | 运行日志 |

**密码不写入任何文件**，只保存在进程内存里，退出即丢。配置文件损坏时会自动备份为 `config.json.bak` 并回落到默认配置。

若本机还留着改名前的 `%APPDATA%\SshTunnelManager` 目录，首次运行会自动把其中的配置与日志复制到新目录，原有服务器地址与转发规则不会丢。

## 六、命令行参数

```
Windows-SSH-Plane.exe                 启动即弹密码框并连接（默认）
Windows-SSH-Plane.exe --no-autoconnect  只打开主界面不连接，首次点“连接”时才要密码
Windows-SSH-Plane.exe --selftest        无界面自检（配置读写、规则校验、端口连通性），结果同时写入 %TEMP%\Windows-SSH-Plane-selftest.txt
```

## 七、编译（需要时）

```bat
build.cmd              生成依赖框架的版本，输出到 dist\（体积小，需要 .NET 10 桌面运行时）
build.cmd selfcontained 生成自包含单文件版本，输出到 dist-selfcontained\（体积大，目标机无需装运行时）
```

或直接用 SDK：

```bat
dotnet publish -c Release -o dist
```

源码结构：

```
Windows-SSH-Plane/
├─ Program.cs              入口：密码弹窗、命令行参数
├─ Core/
│  ├─ AppConfig.cs         配置模型（服务器、保活、规则）
│  ├─ TunnelRule.cs        单条 -R 规则
│  ├─ ConfigStore.cs       config.json / app.log 读写
│  ├─ TunnelService.cs     SSH 连接 + 多条反向转发 + 看门狗重连
│  └─ SelfTest.cs          无界面自检
└─ UI/
   ├─ PasswordForm.cs      登录（密码）弹窗
   ├─ RuleEditForm.cs      新增/编辑转发规则
   └─ MainForm.cs          主界面（规则表格、状态、日志、托盘）
```

技术实现：进程内 SSH 客户端（NuGet 包 `SSH.NET`），因此可以在同一条连接上动态挂载/卸载多条 `ForwardedPortRemote`，不需要像调 `ssh.exe` 那样靠外部进程和 DLL 注入来喂密码。

## 八、边界与注意

1. **只支持密码登录**。若服务器在 `sshd_config` 里设了 `PasswordAuthentication no`（只允许密钥），本程序会提示认证失败，需要改服务器配置或另行扩展密钥登录支持。
2. 主机指纹**不做持久化校验**（首次连接直接接受），如果你需要防中间人校验，可以在 `TunnelService.DoConnect` 里挂 `HostKeyReceived` 事件做固定指纹比对。
3. 转发的是 TCP；服务器侧绑定地址默认 `127.0.0.1`（只允许本机访问），若要让外部访问可改成 `0.0.0.0`，但需服务器 `sshd_config` 允许 `GatewayPorts`。
4. 程序常驻托盘运行，退出时先「断开连接」再关闭窗口更稳妥（程序也会自动断开）。
